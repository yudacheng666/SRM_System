# 轻量 SRM V1 开发规划

## 0. 当前状态

- M0：**进行中**
- 已建立可点击交互原型：`prototype/m0/index.html`
- 当前仅验证长清单、双向多对多分配、Coverage 与报价比较，不接真实数据。

## 1. 开发目标

先完成可本地离线运行的 V1，用于验证核心业务链：

```text
RFQ → 导入拟询价物料 → 供应商分配 → 生成询价单
→ 导入报价 → 比价选择 → 历史沉淀
```

V1 不追求完整 SRM，不重复 ERP、库存、财务、合同、供应商门户等能力。

## 2. 技术原则

- 本地离线运行，正常使用不依赖网络。
- 源码模块化，最终可构建为便于本地使用的静态 HTML 应用。
- UI、业务逻辑、数据访问层分离。
- 本地数据使用 IndexedDB。
- Excel 导入/导出能力随应用离线打包。
- 后续服务器化时，优先替换数据访问层，不重写业务规则。
- 所有仓库示例、测试数据、截图和文档必须使用虚构或匿名信息。

建议分层：

```text
UI
↓
Application / Business Services
↓
Repository / Data Access
↓
IndexedDB
```

## 3. V1 里程碑

### M0 — 交互原型

先验证三个最复杂页面，不接真实数据：

1. 本次询价物料清单（查阅/筛选/图纸预览）
2. 询价分配中心
3. 报价比较

重点验证：
- 长清单筛选与批量选择
- 本次询价物料支持单条输入、剪贴板批量粘贴、文件导入演示
- 本次询价物料支持批量删除，并同步清理相关分配关系
- 演示字段可新增/删除、自定义字段可批量更新
- 全字段模糊搜索 + 每个字段独立模糊筛选
- 所有复选框型清单统一支持可靠的 Shift 连选，不只局限于物料分配清单
- 物料 → 供应商、供应商 → 物料双向操作
- 供应商视角勾选框直接代表关联状态
- 本次 RFQ 供应商列表由采购员主动添加，并可确认后移出
- 供应商名称/编码模糊搜索
- 复制其他供应商的物料范围作为分配起点，再做差异调整
- 多对多关系追加而不覆盖
- 三态选择：未关联 / 部分关联 / 全部关联
- Coverage 检查
- 比价横向展示
- 物料行图纸缩略图及 HTML 内放大预览
- 比价默认选择最低有效报价

完成标准：核心操作路径无需解释即可完成，不存在明显误覆盖风险。

### M1 — 数据基础

实现：
- 供应商主数据
- 物料主数据
- 历史采购数据
- 简单物料分类
- 根据实际 ERP 字段确定生产字段模型与映射
- 可配置扩展字段
- Excel 批量导入
- 导入预览、错误提示、导入日志
- 自定义字段新增/删除
- 选中记录的字段批量更新
- 通用字段级模糊搜索/筛选能力
- IndexedDB 数据层
- 完整备份与恢复

完成标准：数据可导入、查询、关闭应用后保留，并可完整备份恢复。

### M2 — RFQ 与拟询价清单

实现：
- RFQ 流水号
- RFQ 列表与状态
- 新建/编辑 RFQ
- 通过 Excel/文件导入、单条输入、剪贴板批量粘贴建立拟询价物料
- 导入/粘贴预览与重复编码校验
- 搜索、筛选、批量操作
- 项目/设备等作为可选关联字段

业务上不设置拟询价物料数量上限。

完成标准：可从 Excel 建立一份大批量 RFQ，并稳定保存。

### M3 — 询价分配中心

实现：
- 本次候选供应商池
- 按物料分配供应商
- 按供应商分配物料
- 历史采购/历史报价/分类辅助推荐
- 单条与批量追加
- 供应商视角直接勾选/取消关联
- Shift 连选
- 复制其他供应商物料范围后差异化调整
- 三态关联状态
- 批量移除
- 操作结果提示
- 撤销最近批量操作
- Coverage 检查

Coverage 仅提示，不阻止后续生成。

完成标准：复杂多对多分配过程中，新增关系不得隐式覆盖已有关系。

### M4 — 供应商询价单生成

实现：
- 供应商专属询价单逐份预览
- 按供应商拆分已分配物料
- 一键生成供应商专属 Excel
- 稳定的 RFQ Line ID
- 未分配物料继续保留
- 支持后续补充分配并再次生成

完成标准：同一 RFQ 可生成多份内容不同的供应商询价单，且每行可追溯回原 RFQ 明细。

### M5 — 报价导入

实现：
- Excel 报价导入
- 优先利用 RFQ / Supplier / Line ID 自动识别
- 列字段映射
- 保存供应商导入模板
- 原始值与标准化值并存
- 报价轮次 / 议价轮次
- 首轮报价与二次谈价结果分别保留
- 二次谈价允许价格不变
- 未报价 / 不供货 / 部分报价状态
- 导入异常提示

完成标准：不同列结构的报价表可以经过映射后进入统一报价数据模型。

### M6 — 比价与选择

实现：
- 价格、交期、MOQ 横向比较
- 最低价
- 第二低价
- 上次采购价
- 默认选择最低有效报价
- 报价覆盖率
- 逐物料选择供应商
- 批量选择适用供应商
- 非最低价选择必须填写原因
- 首轮 / 二轮及后续议价价格对比
- 降价金额与降价幅度
- 价格未变化的二次谈价结果记录
- 生成供 OA 审核使用的比价报告
- V1 每项物料最终选择一家供应商

完成标准：从多家报价导入、二次谈价、比价选择到生成 OA 比价报告形成完整闭环。

### M7 — 历史沉淀与发布候选版

实现：
- 物料历史采购价
- 物料历史报价
- 每颗物料 × 每家供应商的历次报价历史
- 历次议价轮次与价格变化
- 物料历史供应商
- 历史 RFQ 分配关系
- 历史选择结果
- 基础历史查询
- 离线构建包
- 公共仓库数据安全检查
- 核心回归测试

完成标准：完成一次 RFQ 后，其数据可直接辅助下一次 RFQ。

## 4. 第一阶段暂不开发

以下功能不阻塞 V1：

- 供应商门户
- 在线报价
- 复杂审批
- 合同管理
- 拍卖/竞价
- 财务和付款
- 库存和仓储
- OCR / 图片识别
- AI 自动决策
- 高级供应商评分
- 大型 Dashboard
- ERP API
- 多人权限体系
- 单物料多供应商数量拆分

只为后续扩展预留必要数据边界。

## 5. 关键验收规则

### 多对多分配
新增供应商必须是追加关系，不得覆盖既有供应商。

### Coverage
低于 100% 时允许继续生成询价单，仅生成已分配部分。

### 数据追溯
询价明细、供应商询价单、返回报价、标准化报价和最终选择之间必须可追溯。

### 报价原始数据
标准化不得覆盖或销毁导入原始值。

### 大数据量
业务规则不设置固定条数上限。页面使用分页、虚拟滚动、筛选和批量处理，避免一次渲染全部记录。

### 离线
核心 RFQ 流程在断网环境下可完整运行。

### 公开仓库
自动化测试和演示只能使用合成数据，不允许提交真实业务数据。

## 7. 开发顺序

不要先把所有页面全部做完。

推荐顺序：

```text
M0 交互原型
↓
M1 数据基础
↓
M2 RFQ
↓
M3 双向分配
↓
M4 询价单
↓
M5 报价导入
↓
M6 比价选择
↓
M7 历史与发布
```

其中 M0、M3、M5 是返工风险最高的阶段，应优先验证，不宜为了界面完整度提前扩展非核心模块。


## 8. V1 之后的规划项

### 物料图纸 / 技术文档预览

后续规划在物料主数据中建立图纸或技术文档关联。

目标交互：
- 在询价分配界面选择某颗物料
- 点击“预览图纸”
- 在当前 HTML 应用内打开侧边或弹层预览
- 采购员无需切出系统即可参考图纸判断供应商适配性

第一阶段优先支持 PDF、PNG、JPG 等浏览器离线可稳定预览格式。DWG/DXF 等 CAD 原生格式视技术方案采用转换预览或专用查看组件。

该功能不阻塞 V1 发布，但数据模型应避免未来无法挂接多个图纸/文档。


## 9. 通用交互约束

- 所有加入工作范围的操作，原则上必须有对应的移出/删除能力；审计不可删除的数据除外。
- 删除时必须明确提示关联影响。
- 所有通用数据表字段默认具备字段级模糊搜索能力；新增的可配置字段自动继承。
- 表结构不得以 M0 演示字段为最终标准，正式开发前以 ERP 字段、导入映射和采购业务字段共同确定。


## 10. 本轮 M0 通用交互补充

### 剪贴板录入
- 支持中英文逗号、分号混用
- 支持换行、Tab 与简单空格分隔
- 必须先解析预览再确认写入

### 搜索
- 输入过程中不自动搜索、不重绘页面
- 支持多个字段先分别输入条件
- 点击“搜索”后统一按多条件执行
- 不同字段条件默认 AND 组合

### 清单选择
凡具备多选能力的清单统一提供：
- 全选（当前筛选结果全部）
- 本页全选
- 反选（当前筛选结果全部反转）
- 本页反选
- Shift 连选

### 翻页
所有分页业务清单统一提供：
- 上一页 / 下一页
- 数字页码
- 当前页高亮
- 大页数省略显示

### 字段值批量更新
支持两种方式：
1. 选中记录后，将指定字段统一写入同一个值；
2. 导入更新表，根据指定关键字段匹配记录，再批量更新目标字段。

正式版需增加更新预览，并区分匹配成功、未匹配、重复关键值和格式错误。

### 字段维护归属
字段定义新增/删除、类型、ERP 映射等结构性配置进入“系统设置”。
RFQ 日常业务页面只负责字段值录入、查询与更新。
