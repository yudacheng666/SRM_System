## Windows 专项操作（优先由 Codex Computer Use 执行） / Windows-Specific Steps (Prefer Codex Computer Use)

1. **在更新源文件前**保留旧程序目录并用系统提供的 S4 完整备份功能生成一份可验证 ZIP；关闭原本地服务器 CMD。
1. Before replacing source files, keep the old program directory, create a verifiable S4 complete backup ZIP and stop the old localhost server.
2. 下载 **UI V1 分支的完整源代码 ZIP**，解压到新的测试目录，进入 `prototype\m1-lite\`，双击 `run_local.bat`，在浏览器打开 `http://127.0.0.1:8765/`。
2. Download the **complete UI V1 branch source ZIP** into a fresh test folder, double-click `prototype\m1-lite\run_local.bat` and open `http://127.0.0.1:8765/`.
3. 检查顶部“采购询价工作台”、当前询价摘要及“询价项目 / 数据与备份 / 字段设置”入口。
3. Check the buyer workspace header, active RFQ identifier, and Project/Data/Settings shortcuts.
4. 点击“新建空白正式工作”，确认新的 RFQ 项目名称更新，自动保存提示成功；刷新 F5 仍能打开刚才的工作。
4. Create a new formal RFQ, verify the active RFQ label and confirmed autosave; F5 should preserve the project.
5. 依次进入四步导航：物料与图纸、供应商与分配、报价回收、比价议价，确认布局清晰、无功能区意外消失。
5. Visit all four workflow tabs and verify logical grouping and that no business tools disappear.
6. 在“物料与图纸”中找到图纸匹配管理；在“供应商与分配”点击“添加 / 导入供应商”，能够展开供应商工具。
6. Access PDF management in Items; click Add/Import Suppliers in Assignment to open the supplier drawer.
7. 点击顶部“数据与备份”后确认 S4 完整 ZIP、兼容 JSON、业务报表入口保留；不得将供应商外发包与 S4 恢复 ZIP 混淆。
7. Expand Data & Backup and verify S4 ZIP, legacy JSON and report options remain distinct.
8. 打开“字段设置”并返回任意业务页面，确认所有询价行与供应商关系仍在，导航不导致无意义的数据库修订。
8. Open Field Settings, return to a business tab and confirm existing items/relationships remain; navigation must not create unnecessary revisions.
9. 尝试按业务流程导入虚构物料、分配虚构供应商、导入虚构报价与 PDF，并生成相应比价/外发文件（复用既有 S3/S4 人工验收流程）。
9. With synthetic materials, suppliers, quotations and PDFs, test the existing S3/S4 flow and exports.
10. 将页面布局问题按“页面、操作、预期、实际、截图”记录给 ChatGPT；不要对运行中的 SQLite 或备份目录做破坏性操作。
10. Report layout defects with page, action, expected vs actual result and screenshot; do not destructively modify the active SQLite/backup folder.

- 四步业务导航和工具入口可访问，不丢失任何以前可用的功能。

- Autosave, S4 backup, quote history and original PDF protection are unchanged.
