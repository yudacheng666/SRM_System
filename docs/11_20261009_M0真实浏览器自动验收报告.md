## 四、自动验收前修复的问题
## 4. Defect repaired before acceptance

核查测试流程时发现：原版 M0 在页面初始化时就提前为默认供应商建立首轮应报价范围快照；后续采购员再导入物料并补充分配时，首次报价可能被误判为“多报”。
During test preparation, inspection identified premature initialization of the default supplier's Round 1 expected-scope snapshot on page load; later imported and newly assigned items could be mistakenly treated as extra quotes.

已把首轮报价范围初始化推迟到采购员进入“报价回收导入”时；实际 100×10 浏览器测试已从导入、分配、首轮报价到二轮确认全流程验证这条修复路径。
The first expected-scope snapshot is now initialized when the buyer opens Quotation Return; the actual 100×10 browser workflow passed import, assignments, Round 1 return and Round 2 confirmation through this corrected path.

修复仅提交到浏览器验收草稿分支，并未覆盖 `main`。
The fix exists only on the browser-acceptance draft branch; `main` remains unchanged.
