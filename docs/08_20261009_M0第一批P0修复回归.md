## 二、修复结果
## 2. Implemented fixes

### AUD-01 报价演示隔离
### AUD-01 Synthetic quotation isolation

保留尚未进入报价回收时的纯虚构报价比较演示；进入“报价回收导入”后切换到回收验证模式，清除之前用于演示的选择，未确认或未回收的报价不再自动生成模拟金额。
The pure synthetic comparison demonstration remains available before entering quotation return. Opening Quotation Return switches to returned-quotation mode, clears prior demo awards, and never fabricates amounts for missing or unconfirmed supplier quotations.

已确认的真实回收报价仍可参与比较，界面明确标识两种模式；上次采购价仍是虚构示例，尚不连接 ERP。
Confirmed returned quotes remain eligible for comparison, and the interface labels both modes. Previous purchase prices are still synthetic placeholders, not ERP data.

### AUD-02 重复键更新保护与提交前预览
### AUD-02 Duplicate-key update guard and pre-commit preview

匹配更新不再使用“找到第一条就直接修改”。现在先计算唯一命中、未匹配、多候选、重复输入键和非法数值，生成完整预览。
Matched updates no longer use first-hit mutation. They first classify unique hits, missing keys, ambiguous matches, repeated input keys and invalid values, then display a complete preview.

多候选、重复输入、非法值或已确认历史冲突时，整批确认按钮禁用；没有命中的记录明确作为跳过项标记；提交前再次校验并要求确认。
Ambiguous, duplicate, invalid or history-protected data blocks batch confirmation; misses are visibly skipped; matching is revalidated immediately before explicit commit.

批量字段更新同样增加已确认历史保护，避免绕过新校验流程直接改变已确认询价行。
Bulk field edits also check confirmed-history protection to prevent bypassing the guarded update path.

### AUD-03 已确认报价历史保护
### AUD-03 Confirmed-quotation history protection

新增统一的 `hasConfirmedItemHistory`、`guardMutableLines` 和 `changeSupplierRelations` 业务函数，对已确认报价涉及的询价行进行保护。
Added shared business functions `hasConfirmedItemHistory`, `guardMutableLines` and `changeSupplierRelations` to protect RFQ lines covered by confirmed submissions.

按物料分配、按供应商直接勾选、Shift 连选、全选/反选/取消关联、复制供应商范围，以及移出本次询价供应商，都先校验实际受影响的行。
Item-first changes, supplier-first checkboxes, Shift ranges, link/invert/unlink bulk actions, copying supplier coverage and removing suppliers from an RFQ now preflight affected lines.

只要一次操作会更改任何已确认报价关联的物料，整批拒绝，不允许一部分已改、一部分未改；已确认后变更数量/单位等属性也被拦截。
If any affected line is protected, reject the whole operation atomically rather than partially changing links; quantity/unit and other bulk property changes on confirmed lines are also blocked.

M0 尚未实现正式 RFQ 修订事务，因此拦截时提示用户以后通过正式修订进行处理；本轮不伪造该流程。
M0 does not implement production RFQ amendment transactions; blocked changes point to future formal revision workflows instead of inventing them in this batch.
