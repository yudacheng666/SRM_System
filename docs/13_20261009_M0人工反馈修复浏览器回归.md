## 二、新增七条反馈处理
## 2. Seven buyer comments

**UAT-01：物料双击编辑。**
**UAT-01: Double-click material-row editing.**

在本次询价物料列表双击行，打开页面内编辑窗口，可修改物料编码（存货编码）、数量、名称、分类、单位；保留不变的 RFQ Line ID 与现有供应商分配，验证正数数量。已有保存报价行或确认历史时只读，不允许原位覆盖。
Double-click a material row to edit item code, quantity, name, category and unit; retain stable RFQ Line ID and supplier links, enforce positive quantity. Any saved quotation or confirmed history makes the row read-only.

这是 M0 当前行现有字段带出，不是 ERP 实际主数据自动补齐；改码不自动合并不同 RFQ 行；新老编码溯源与完整 ERP 字段映射留待后续阶段。
These fields are populated from the existing M0 row, not actual ERP master-data autofill. Code edits do not automatically merge RFQ lines; historical code mapping and official ERP field mapping remain later work.

**UAT-02：报价粘贴、预览、明细表头。**
**UAT-02: Consistent quotation paste, preview and details labels.**

已知 M0 字段统一显示“物料编码 / RFQ Line ID / 单价与阶梯价 / 交期 / MOQ / 报价状态”。预览单列显示物料编码、RFQ Line ID、名称；明细表在标题中说明同时显示的内容，具体金额列标注当前演示单位。
Known M0 field labels are consistent across paste, preview and quote detail. Item code, RFQ Line ID and name have explicit preview columns, and detail/price headings state represented fields and demo units.

完整 ERP 物料属性与采购计价字段尚未正式映射，不能把 M0 中文表头当成 ERP 全量字段方案已验收。
Complete ERP item and purchasing-pricing fields remain unmapped; the M0 headings are not a finalized ERP data dictionary.

**UAT-03：供应商排序。**
**UAT-03: Supplier ordering.**

报价供应商下拉框对 `SUP-001`、`SUP-002` 等采用自然数字升序，不再跟随添加先后顺序；保留当前有效选择。
Quotation supplier options sort naturally by supplier code rather than insertion order, preserving the selected option.

**UAT-04/05：单条报价单位、交期。**
**UAT-04/05: Explicit manual quote units and lead time.**

单价显示“元/物料单位”；交期显示“天”；MOQ 显示“最小起订量（物料单位）”，报价状态有独立字段标签；M0 仍按人民币示例，不得推定 ERP 的税口径和其他币种已配置。
Quote price is labeled yuan/item unit, lead time days, and MOQ item units; quote status has an explicit label. The current M0 uses demo yuan assumptions without asserting ERP tax/currency mapping.

**UAT-06：共同报价项。**
**UAT-06: Common quotation items.**

尚未修改现有共同报价金额算法；先行保存三种口径的重设计建议 `docs/12_20261009_M0人工反馈与共同报价口径待确认.md`，等待用户决定。
Existing common-scope total formulas remain unchanged; three candidate comparison bases are documented in `docs/12_20261009_M0人工反馈与共同报价口径待确认.md`, pending buyer approval.

**UAT-07：非最低报价选择。**
**UAT-07: Non-lowest supplier choice.**

此前已把原生 `prompt` 替换成页面内原因窗口并扩大整个报价单元格点击范围。现在专项 Chromium 实测验证：点击非最低报价后打开窗口；不填原因无法确认；填写原因后保存选择，点击对应报价区域有效。
The previous native `prompt` has been replaced by an in-page reason modal and clickable quote cell. Real Chromium tests now verify it opens, refuses blank reasons and saves the explained non-lowest selection.
