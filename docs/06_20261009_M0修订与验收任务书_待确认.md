## 2. M0 修订与复核清单
## 2. M0 revision and verification checklist

### M0-01 本次询价物料录入【R/U/N】
### M0-01 Inquiry item entry [R/U/N]

支持单条输入、剪贴板批量粘贴、CSV/TXT 文件；Excel 在 M0 仅提供明确标识为模拟的交互，不伪装为正式解析。
Support single-row entry, bulk clipboard paste, and CSV/TXT files. Excel remains an explicitly marked M0 simulation, not a production parser.

剪贴板及 CSV/TXT 的第一行必须是列标题，第二行起是数据；物料导入必须精确包含“物料编码”列标题，非主键列允许按规则省略，列顺序可调整。
Clipboard and CSV/TXT data require a header in the first row and data from row two; item imports require the exact “物料编码” header, optional columns may be omitted, and column order may vary.

必须正确处理 Excel Tab、逗号及引号转义、保留空字段的位置；中英文分号可作为记录分隔，普通空格绝不拆分字段。
Correctly parse Excel-style tabs, commas and quoted fields while preserving blank positions; Chinese/English semicolons may separate records, but ordinary spaces must never split fields.

数量、价格等非法值不得静默变成 0 或 1；数量及单位是本次询价业务必需数据，缺失时必须明确校验。
Invalid quantities or prices must never silently become 0 or 1; inquiry quantity and unit are required transaction data and missing values require explicit validation.

导入流程统一为“输入 → 预览 → 异常检查 → 确认写入”，可清空输入和预览内容；取消导入不得修改原有清单。
Use one input → preview → error validation → confirm workflow, with controls to clear input and preview; cancellation must not mutate existing items.

### M0-02 列表、搜索、排序与选择【R/U/N】
### M0-02 Lists, filtering, sorting and selection [R/U/N]

列表中 RFQ Line ID、物料编码、图纸应为三个独立并对齐的列，图纸列提供可点击的 PDF 式缩略示意。
Render RFQ Line ID, item code, and drawing in three separately aligned columns with an interactive PDF-like thumbnail.

默认按最新新增倒序；适合的列支持升序/降序，Shift+点击列标题设置多字段优先级排序；分页前对完整筛选结果排序，稳定保持顺序。
Default to newest-first; sortable columns support ascending/descending order and Shift+click priority-based multi-field sorts; sorting applies before pagination and remains stable.

所有搜索区支持按字段模糊搜索及多条件 AND；输入条件和已应用条件分离，必须点击“搜索”或按 Enter 才正式生效，同时提供“清空条件”。
All search areas support fuzzy per-field queries and multi-condition AND logic; draft inputs remain separate from applied filters until Search/Enter, with a Clear Filters control.

所有可多选清单统一支持全选当前筛选结果、本页全选、反选当前筛选结果、本页反选、Shift 连选以及取消临时选择；翻页不能丢失已选择项目。
All multi-select lists support Select All Filtered, Select Page, Invert All Filtered, Invert Page, Shift range-selection, and Clear Temporary Selection; changing pages must preserve selection.

分页显示上一页、下一页、数字页码、当前页及大页数省略；取消临时选择不得取消已经确认的供应商业务关联。
Pagination includes previous/next, numbered pages, active page and ellipsis; clearing temporary selection must not erase committed supplier relationships.

### M0-03 同编码物料合并与 RFQ 行身份【R/U/N】
### M0-03 Same-code consolidation and RFQ line identity [R/U/N]

同一 RFQ 内，相同存货编码且名称、单位、分类、技术/交付等关键条件兼容时，允许合并询价数量；必须保留每一条原始需求来源以便审计和拆分追溯。
Within an RFQ, equal item codes may consolidate quantity only when name, unit, category, technical and delivery conditions are compatible; retain every source demand for audit and traceability.

条件冲突、多候选、已分配、已发询价包或已报价的记录不得静默合并；明确提示并允许取消整批或人工确认独立保留。
Conflicts, ambiguous candidates, already-assigned, issued or quoted lines must never be silently merged; show warnings and allow cancelling the batch or explicitly retaining separate lines.

合并数量只用于真实兼容的同编码需求，不能依据参考编码相同或新老料号关联直接合并；任何已形成的 RFQ Line ID 不得被无痕替换。
Quantity consolidation applies only to truly compatible same-code demands, never merely shared reference codes or old/new code links; existing RFQ Line IDs must not be silently replaced.

报价回收、供应商分配、图纸关联、删除保护都使用稳定 RFQ Line ID，而不是依赖行号或物料编码唯一性。
Quotation return, supplier assignment, drawing links, and deletion safety depend on stable RFQ Line IDs rather than row position or presumed unique item codes.

### M0-04 本次供应商池与多对多分配【R/U/N】
### M0-04 RFQ supplier pool and many-to-many assignment [R/U/N]

采购员主动添加本次参与询价的供应商，允许从当前 RFQ 移出；不得直接把全体供应商作为本次供应商清单。
Buyers explicitly add suppliers to the current RFQ and may remove them; the entire supplier master list is not automatically the RFQ pool.

提供按物料分配供应商、按供应商分配物料两种视角；新关联默认追加，绝不隐式覆盖既有关联。
Support both item-to-supplier and supplier-to-item assignment; added relationships append and never silently replace existing ones.

已关联、部分关联、未关联的状态应可辨识；供应商视角勾选框直接反映真实关联，不能出现点选后被其他操作顶掉。
Clearly distinguish full, partial, and absent relationships; supplier-side checkboxes represent actual relationships without accidentally dropping previous assignments.

支持复制其他供应商的物料范围后做差异增删；Coverage 低于 100% 仅提示，仍可为已分配的范围生成询价单。
Allow copying another supplier’s coverage and editing differences; coverage below 100% is advisory and must not block RFQ generation for assigned lines.

### M0-05 图纸预览与供应商专属询价包【R/U/F】
### M0-05 Drawing preview and supplier-specific RFQ packages [R/U/F]

M0 用虚构数据验证一物料多 PDF、多页、缩略图/大预览、页码切换、缩放和共享附件提示；不得把模拟界面描述成已支持真实 PDF 文件。
Use synthetic scenarios to validate multiple PDFs per item, multiple pages, thumbnails/full previews, page navigation, zoom and shared-attachment indicators; do not claim real PDF file support.

按每个供应商已分配的物料预览其个性化询价范围，提示缺图纸、重复/共享图纸；未分配物料不能混入该供应商询价包。
Preview supplier-specific assigned lines and surface missing, shared or duplicate drawings; unassigned lines must not leak into a supplier package.

真正的询价 Excel、PDF 文件收集、ZIP 打包以及发送时附件版本快照属于后续 M4 正式实现。
Production inquiry Excel generation, PDF collection, ZIP packaging, and issued-attachment snapshots belong to M4.

### M0-06 报价回收导入与字段识别【R/U/N】
### M0-06 Quotation return and field recognition [R/U/N]

支持单条录入、剪贴板粘贴、CSV/TXT 及 Excel 模拟入口；导入后可在未确认草稿中改值，提供输入清空、预览及异常反馈。
Support manual entry, pasted records, CSV/TXT and a simulated Excel entry point; allow editing draft rows and provide input-clear, preview and error feedback.

报价粘贴第一行必须为列标题，并至少精确包含“RFQ Line ID”或“物料编码”；两者同时存在时优先非空 Line ID，仅在物料编码对应唯一 RFQ 行时允许回退。
Quotation pastes require a first-row header with exact “RFQ Line ID” or “物料编码”; prefer a nonempty Line ID and fall back to an item code only where the RFQ row match is unique.

允许字段乱序及非必需列缺失；状态列缺失但有有效价格时可判为“正常报价”，价格和状态均缺失时为“待检查”；无效状态不得写入有效报价。
Allow reordered and omitted optional fields; a valid price with no status column may mean Quoted, while both status and price absent means Review Required; invalid statuses must not become effective quotations.

报价状态显示清楚的中文“正常报价、明确未报价、不供货、待检查”，不得显示内部 null、undefined 或原始枚举给采购员。
Display clear Chinese status labels for quoted, explicit no-quote, cannot-supply and review-required states; never expose internal null, undefined, or raw enums to buyers.

无邮件的报价可关联聊天截图或单独 PDF；有邮件时以原始邮件及附件作为来源证据，手工报价需保留来源说明；M0 只验证输入及模型，不上传到供应商门户。
Link alternative evidence such as chat screenshots or standalone PDFs when email is absent; preserve original email and attachments when available and source notes for manual entry. M0 validates the model only, with no supplier portal.

### M0-07 报价轮次、版本、范围与历史【R/U/N】
### M0-07 Quotation rounds, versions, scope and history [R/U/N]

区分“第 N 轮”议价阶段与同轮“第 M 版”更正提交；已确认的旧版本不能覆盖，RFQ 本身的修订也不得与报价版本混淆。
Distinguish negotiation Round N from correction Submission Version M within a round; confirmed versions are immutable and must not be confused with RFQ revisions.

每轮单独记录本供应商应报价 RFQ Line ID 范围；后轮允许只针对部分物料议价，其他物料按明确业务规则展示。
Snapshot the supplier-specific expected RFQ Line IDs for each round; later rounds may target only selected items and non-targeted items follow explicit display rules.

本轮应报价而漏报的行，不能自动沿用上一轮；必须由采购员明确确认“沿用上轮”，且不能跨过明确未报价/不供货状态回溯到更早价格。
A line missing from the current expected round cannot silently inherit a prior price; carry-forward requires explicit buyer confirmation and cannot leap past explicit no-quote or cannot-supply statuses.

相同价格重新提交仍要保存新轮次/新版本，议价降幅为零；已确认历史与关联对象不能被物理删除造成孤儿记录。
Resubmitting the same price still creates the relevant round/version record with zero price change; confirmed history and linked records must not be physically deleted into orphan records.

### M0-08 报价覆盖、漏报导出与校验【R/U/N】
### M0-08 Quotation coverage, omission export and validation [R/U/N]

以每家供应商、每轮实际应报价范围为基准，区分正常报价、明确未报价、不供货、漏报、多报、重复及数据错误。
Against the expected scope for each supplier and round, distinguish quoted, explicit no-quote, cannot-supply, omitted, out-of-scope, duplicate and invalid rows.

漏报不等于明确未报价；多报、重复、无唯一身份或数据错误不直接进入有效比价。
Omitted is not the same as explicit no-quote; out-of-scope, duplicate, unidentifiable or invalid rows cannot directly enter valid comparisons.

当前供应商/当前轮次的漏报项目可以导出 CSV，包含 RFQ Line ID、物料编码、数量、单位等追溯字段；浏览器需实测下载内容与中文编码。
Export missing items for the selected supplier and round as CSV, retaining RFQ Line ID, item code, quantity, and unit; verify actual download content and Chinese character encoding in a browser.

### M0-09 阶梯价与报价可比性【R/U/N】
### M0-09 Tiered prices and comparability [R/U/N]

普通单价与阶梯价格使用统一报价模型，保存完整数量区间；按本次 RFQ 数量选取适用档位，重叠、倒置、非法价格或数量不落档均明确报错。
Regular and tiered prices share one quotation model and retain all quantity brackets; resolve the applicable tier by RFQ quantity and reject overlaps, inverted ranges, invalid prices or unmatched quantities.

未报价不能按零价格计算；币种、含税/未税、采购单位或数量口径不可比时必须提示，正式多币种/换算逻辑留待后续实现。
Missing quotes cannot be priced as zero; warn about incompatible currency, tax treatment, purchasing units or quantities, leaving production currency conversion to later milestones.

### M0-10 逐项比价、总价与最终选择【R/U/N】
### M0-10 Line comparisons, totals and final award [R/U/N]

逐项列出供应商有效报价、阶梯适用价、交期、MOQ、报价轮次与覆盖状态，默认选最低有效报价；非最低价改选必须填写原因。
Show valid supplier quotes, applicable tiers, delivery time, MOQ, round and coverage per item; default to the lowest valid quote and require a reason for a non-lowest choice.

至少验证供应商自身有效报价范围总额、共同物料范围总额、理论最低总额和最终选择总额；指定范围总额的界面按现有基线复核。
Verify supplier quoted-scope totals, common-scope totals, theoretical minimum totals and final selected totals; review the custom-scope total interaction against the existing baseline.

不得把不同供应商不相同的物料范围总价直接横向比较；不应限制固定前 N 家供应商或前 N 行物料。
Never compare total prices over nonidentical supplier coverage as if directly comparable; do not limit comparisons to a fixed initial number of suppliers or item lines.

正式 OA 比价报告的版式、文件生成和审批附件输出属于 M6；M0 重点核对必需的数据是否已可追溯。
Production OA comparison report layout, file generation and approval attachments belong to M6; M0 verifies that the necessary data is traceable.

### M0-11 字段配置、更新和删除安全【R/U/N】
### M0-11 Field configuration, updates and deletion safety [R/U/N]

字段定义的新增/删除、类型及映射配置统一位于“系统设置”；业务界面只修改字段值。
Field definition, removal, typing and mapping belong in System Settings; business views edit values only.

支持所选记录统一批量改值及按关键字段匹配的导入更新演示；匹配、未匹配、重复键、类型错误应预览提示。
Demonstrate bulk field-value edits and key-matched import updates; preview matched, unmatched, duplicate-key and type-error outcomes.

“有添加应有删除/移出”适用于未确认业务对象；一旦涉及已发询价包、已确认报价或审计历史，应作废/取消参与并保留追溯。
Pair add actions with delete/remove for uncommitted objects; issued packages, confirmed quotes and audited records require deactivation or participation cancellation while preserving history.

### M0-12 演示数据与操作可理解性【U/N】
### M0-12 Fixtures and usability [U/N]

测试用虚构的 100 条物料、10 家供应商、覆盖范围不同的多轮报价组合，表头与当前 M0 导入规则严格一致。
Use synthetic test fixtures containing 100 items, 10 suppliers and multi-round quotes with varying coverage, with headers matching current M0 import rules exactly.

实际验收必须检查界面术语通俗、不会出现重复添加和确认按钮混淆、已关联状态清楚、修改与删除后有明确反馈。
Hands-on acceptance must confirm plain-language labels, no confusing extra Add/Confirm actions, visible committed assignments, and clear feedback after edits or removals.

## 3. 必测场景与通过门槛
## 3. Mandatory scenarios and acceptance gates

A01：用顺序打乱的物料表头粘贴，保留空白字段；缺精确“物料编码”标题应拒绝；含“304 不锈钢”的值不拆列。
A01: Paste reordered item headers and preserve blanks; reject a missing exact “物料编码” header and do not split “304 不锈钢”.

A02：导入数量为 0、abc、空值及含引号的 CSV，检查逐行错误和取消后清单不变。
A02: Import zero, abc, blank and quoted CSV values; verify row-level errors and no mutation after cancellation.

A03：粘贴同码兼容物料，合并数量而保留源行；遇单位/技术条件冲突、已分配或已报价行不允许静默合并。
A03: Consolidate compatible equal-code items with source retention; never silently merge conflicts or assigned/quoted items.

A04：多个字段先填写搜索条件，再点击搜索，检查结果、焦点、清空；翻页和 Shift 多选不触发未提交条件。
A04: Stage multi-field search criteria before applying; validate results, focus, clear controls, and that paging/Shift selection does not apply drafts.

A05：连续选择、跨页选择、全选筛选结果/本页全选/反选/取消选择，并验证不影响已确认供应商关联。
A05: Exercise ranges across pages, all/page select, invert and clear selection without altering committed supplier links.

A06：新增物料后检查默认最新在前；测试单字段、Shift 多字段排序以及筛选/分页后的稳定结果。
A06: Verify newest-first after adding items; test single and Shift multi-field sorting and stable filtered/paged results.

A07：为同一物料追加两家以上供应商，切换双视角、复制其他供应商范围，再移除一条关联，其他关系仍保留。
A07: Append multiple suppliers to an item, switch views, copy coverage, remove one relationship, and preserve all others.

A08：设置至少一项物料未分配，Coverage 不满 100% 仍可预览已分配部分，不能丢失未分配行。
A08: Leave at least one item unassigned; allow package preview below 100% coverage without losing the unassigned line.

A09：检查一物料多个 PDF 式附件、多页切换、放大及缺失图纸告警；明确标注这是 M0 模拟。
A09: Check multiple synthetic drawing attachments, page navigation, zoom, missing-file warnings, and unmistakable M0-simulation labeling.

A10：报价表头缺“状态”但有有效价格应识别正常；价格及状态均缺失应待检查；非法状态、不唯一物料编码回退应阻止提交。
A10: Price-only rows without status may be quoted; missing both requires review; invalid status and ambiguous item-code fallback must block confirmation.

A11：分别制造本轮漏报、明确未报价、多报、重复、错误以及不供货，核对覆盖数量和漏报 CSV 导出内容。
A11: Create omitted, explicit no-quote, out-of-scope, duplicate, invalid and cannot-supply cases; validate coverage counts and omission CSV.
