## 二、四项修复
## 2. Four fixes

### AUD-09 导入预览完整性
### AUD-09 Complete item import preview

原预览最多显示前 50 行，现在支持每页 50 行、数字分页、当前范围与总数量，以及“仅看全部错误/冲突”筛选。
Previously only the first 50 rows were visible; the preview now supports 50-row pagination, numbered navigation, visible range/count and a dedicated all-errors/conflicts filter.

异常位于第 51 行甚至更后面时同样可以查看；预览翻页不改变最终提交范围，仍按全部导入行做校验和提交；包含错误行时禁止直接提交。
Exceptions beyond row 50 are visible; preview pagination does not change the commit scope, and all rows are validated together; invalid rows block commit.

### AUD-10 供应商关联文案与确认
### AUD-10 Supplier relationship labels and confirmations

供应商视角的“全选/反选/全部取消”已更名为明确的“关联/反转关联/取消关联”等业务动作，清楚区分临时勾选和即时生效的供应商关系。
Supplier-side “select/invert/cancel all” labels now explicitly describe link, invert link or unlink actions, separating temporary selection from immediate business relationship changes.

批量关联操作先核对实际影响范围与已确认历史保护，再显示受影响数量和供应商，采购员确认后才生效；按物料视角批量添加/移除也走同一确认流程。
Bulk relationship changes now preflight affected lines and confirmed-history guards, show supplier/count, and require buyer confirmation; item-first bulk add/remove uses the same safe path.

### AUD-11 虚构历史采购价格标识
### AUD-11 Explicit synthetic historical purchase-price labels

比价表头改为“模拟上次采购价（虚构）”，每条显示金额旁标记“虚构”；顶部标题同时提醒当前 M0 上次采购价不是真实 ERP 成交记录。
The comparison header now reads “Synthetic previous purchase price,” with each value visibly marked as synthetic; the top-level caption also clarifies it is not a real ERP transaction.

不因本次修改提前接入真实历史数据；ERP 订单执行表历史成交价格属于后续 M1–M7 数据工作。
This change does not introduce real historic price data; importing ERP historical purchase prices remains a later milestone.

## 四、限制和风险
## 4. Limits and known boundaries

本轮通过的是函数逻辑、解析、文案存在性和 DOM 最小替身测试，尚未执行真实浏览器鼠标、键盘、文件选择与下载的端到端测试，不能宣布 M0 最终通过。
These passes cover business functions, parsers, label presence and minimal DOM stubs; actual browser mouse/keyboard, file selection and download flows have not been tested end to end, so final M0 acceptance is still pending.

当前物料测试数据需在报价确认前完成对应供应商关联，第二轮报价前需设置准确的本轮应报价物料范围；否则覆盖检查结果不符合预期。
Fixture users must establish supplier assignments before confirming quotes and set the correct expected scope for each later round; otherwise coverage checks will be misleading.

新修改的重点业务函数采用中英双语注释；此前对“代码逐行注释”的完整要求尚未做全仓逐行审计，不声称已经满足每行代码都有注释。
Key modified business functions have bilingual comments; the broader request for line-by-line comments throughout the codebase has not yet been audited, and full line-level coverage is not claimed.

完整 ERP 物料字段导入、新老料号映射、关联查询、真实 PDF/Excel 和持久化数据层继续按后续版本阶段实施。
ERP field import, old/new material mapping, linked searches, real PDF/Excel and persistent storage remain later-milestone work.
