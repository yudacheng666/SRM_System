# 20261014 SRM Supplier RFQ Package PDF Naming Fix V1

## 问题与结论 / Issues and Decisions

- 人工验收发现：供应商独立询价包额外包含 `图纸关联清单.json`。
- Buyer acceptance found an unnecessary `图纸关联清单.json` in supplier-facing RFQ packages.
- 人工验收发现：PDF 原始文件名被替换为自动编号和哈希，造成辨识困难。
- Buyer acceptance found original PDF names replaced by generated counters and hashes.
- 修复原则：供应商询价包仅提供对应供应商的询价 Excel 和已确认关联的 PDF 原件。
- Fix: A supplier RFQ ZIP contains only that supplier's XLSX and explicitly linked original PDFs.
- 修复原则：直接使用原始上传 PDF 文件名（通常为物料编码或图号），不使用自动编号重命名。
- Fix: Retain the original uploaded PDF filename (often item or drawing number), without autogenerated names.

## 冲突处理 / Collision Policy

- 两个供应商分别打包，不要求不同供应商之间的 PDF 文件名全局唯一。
- Supplier ZIPs are isolated; PDF filenames need not be globally unique across suppliers.
- 同一供应商资料包内若两份不同内容的图纸文件名相同（包括大小写或 Unicode 规范化后相同），整个供应商包导出失败并显示冲突文件名。
- If two different PDF contents share the same effective name (case-insensitively or after Unicode normalization) in one supplier ZIP, refuse that ZIP and identify the collision.
- 同一个 PDF 被多条物料复用时，只在该供应商 ZIP 中放入一份原件，不重复打包。
- Reused identical PDF binaries appear once per supplier ZIP, even when linked to multiple lines.
- 禁止路径分隔符、路径回退、无效扩展名、控制字符和 Windows 非法字符；不静默改名。
- Reject separators, traversal, invalid extensions, control characters and Windows-invalid characters without silent renaming.
- 原始文件哈希核对失败或源 PDF 不可读取时，拒绝导出，不生成不完整资料包。
- Reject export when source PDF content is unavailable or fails SHA-256 validation.

## 内外资料边界 / Internal vs Supplier-Facing Artifacts

- 供应商外发 ZIP：Excel 询价单 + PDF 图纸原件；**不含 JSON 清单**。
- Supplier-facing ZIP: RFQ Excel plus original PDFs; **no JSON manifest**.
- 内部完整备份 ZIP：继续保留 `全部询价结构化数据.json` 和 `图纸文件索引.json`，不受外发包规则影响。
- Internal full backup ZIP: retains `全部询价结构化数据.json` and `图纸文件索引.json`; not affected by supplier packaging rules.
- 此修复不修改物料分配、不改写 PDF 文件内容、不修改 SQLite 已保存记录。
- This fix does not change supplier assignments, PDF bytes or existing saved SQLite records.

## Windows 更新方式 / Windows Update Procedure

- 关闭本机 CMD 服务（Ctrl+C），下载分支 `draft/20261013-m1-storage-ui-audit` 的最新文件，替换原 `prototype/m1-lite/index.html`。
- Stop CMD service (Ctrl+C), download the latest branch file and replace the local `prototype/m1-lite/index.html`.
- 再运行 `python backend\server.py`，并用 `Ctrl+F5` 强制刷新 `http://127.0.0.1:8765/`。
- Restart with `python backend\server.py` and hard-refresh `http://127.0.0.1:8765/` with Ctrl+F5.
- SQLite 与原始 PDF 存在独立用户目录中，本次只需更新页面代码，不用重新导入测试数据。
- SQLite and uploaded PDFs are in an independent user directory; no test-data re-import is needed.
- 复测供应商专属资料包：只出现供应商自己的 XLSX 和 PDF，且 PDF 文件名与导入时一致。
- Recheck each supplier package for only its own XLSX and PDFs, with their original uploaded filenames.
