### 1. 建立一笔完整的虚构询价（ERP 列兼容性是 PR #15 核心）
从空白正式工作开始，通过**真实页面导入流程**分别试 Excel .xlsx 和 CSV/复制粘贴，先预览、确认，再检查数量、列和值：
```csv
存货编码,存货名称,规格型号,所属类别,参考编码1,参考编码2,采购常用单位,询价数量,询价单位,ERP批次属性
TEST-001,虚构轴,M16,机械件,R-100,R-200,盒,2,件,内部标签A
TEST-001,虚构轴,M16,机械件,R-100,R-200,盒,3,件,内部标签A
TEST-001,虚构轴,M20,机械件,R-100,R-200,盒,4,件,内部标签A
TEST-002,虚构支架,板厚4,钣金件,R-101,,件,6,件,内部标签B
```
独立核对 4 个原始记录按既有规则变为 **3 个询价行**：M16=5件、M20=4件、TEST-002=6件。同一编码不同规格不能误合并；测试参考码搜索、分类筛选、排序、逐项编辑、批量更新、改后恢复与保存。检查 `采购常用单位=盒` 与 `询价单位=件` 明确分离，不自动做 1 盒 = N 件的推断。
- 负例：同一行 `存货编码=TEST-A` 与旧表头 `物料编码=TEST-B` 冲突，应明确拒绝且**不污染已有工作**；并检查同编码但不同 ERP 原始附加值不得静默合并。
- 真实 .xlsx 用 200+ 列的虚构宽表测试非映射 `erpExtra` 原列名/原值在内部导出中往返保留，检查 256 列边界和超限时的用户提示；这是**原样留存**，不是 220 个字段均已经语义映射的证据。

### 2. 多供应商、多轮询报价闭环
- 创建至少 3 家**虚构供应商**，执行物料→供应商与供应商→物料两种分配，包含重复选择、取消选择、交叉覆盖及不足 100% 的部分范围；操作后/切换页面后状态不应丢失，允许带明确风险提示的部分询价包生成。
- 为每家生成独立供应商 RFQ XLSX 或 ZIP，解包按**真实文件内容**核对：只含分配给该供应商的物料、必须的规格和空白报价区，不能包含 `参考编码1/2`、`ERP批次属性`、其他供应商报价、历史或内部中选结论。外层“全部供应商”ZIP 只能作为内部下载，不作为可直接外发资料。
- 分别通过 UI 的 .xlsx、粘贴/CSV（若对应入口存在）和手工录入报价；用至少两轮不同报价范围和一次阶梯价。对漏报、多报、重复行、未报价、不供货、整轮商务备注和逐行报价备注进行核验。区分报价凭证来源：手工输入不能冒充 Excel/邮件附件；已确认轮次及其来源与历史不能被下一轮静默改写。若 UI 不支持某来源/功能，记录 `NOT TESTED / NOT SUPPORTED`，不得编造。
- 在比价页面核对有效报价范围、缺报≠0 元、适用阶梯价、最低价提示、共同范围金额、非最低价选用原因/待复核状态。生成内部比价议价 XLSX，用独立 XLSX 解析器检查数据行、报表结构、来源、轮次、备注及公式/金额（对照手算预期）；区分已实现导出与另行设计、尚未集成的“比价 Excel V2”。
