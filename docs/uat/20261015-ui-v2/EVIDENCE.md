## Trace and harness usage / 使用方式

Download either ZIP and open locally with `npx playwright show-trace <zip>`. The full trace retains resource snapshots, network records, actions and screencast frames; it has not been trimmed or rewritten. The focused trace is smaller for review. Both pass ZIP CRC verification.

[Independent exploratory console](scripts/exploratory-console.cjs) is an audit harness, not a new business test or a claim of a deterministic 40-test suite. Its log records adaptive commands, locator mistakes, transient timeouts and corrections as well as successful operations. A driver exception is not automatically an application defect. Existing app/test files were untouched.

For manual reproduction, start from the tested SHA in an isolated checkout and use an empty `SRM_DATA_DIR`; run the existing `prototype/m1-lite/tests/e2e/serve.py 8825`. Install the repository Playwright dependency if needed. The harness accepts `SRM_UAT_PLAYWRIGHT` (module path), `SRM_UAT_CHROMIUM`, `SRM_UAT_URL`, and `SRM_UAT_EVIDENCE`; send one-line asynchronous Playwright commands on stdin. Copy synthetic fixtures to the logged scratch fixture path or adjust those paths. Follow the specific issue reproduction steps; do not blindly replay the adaptive transcript. Use a separate empty root and port8826 for recovery. Stop tracing before closing Chromium to preserve its ZIP.

No real clipboard permissions/native chooser were exercised: Playwright filled text and supplied synthetic file paths. Browser network-offline mode was the only injected save fault. The PDF black frame and page2 request are not a PDF visual PASS.

## Browser log interpretation

No JavaScript pageerror event was observed. Six console resource errors were logged before harness rebinding: two favicon404s, one expected broken-backup400, and three expected ERR_INTERNET_DISCONNECTED during the deliberate offline test. Such resource errors are retained rather than hidden. The initial harness accepted prompts with empty text, producing a “price cannot be empty” validation; it was then corrected to provide synthetic values, and the revision succeeded. This harness mistake is not counted as a product defect. One PDF screenshot timed out after the page2 request; the retained page1 screenshot and request text establish the NOT TESTED limitation. A short-lived restore-success message was missed by an assertion because restore reloads the page; subsequent UI, snapshot and PDF-hash checks verified actual recovery.
