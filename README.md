# SRM System

A lightweight supplier relationship and RFQ management project.

## Project direction

The first stage focuses on a local offline web application for validating product workflows. A later stage may migrate the proven workflow to a server-based multi-user deployment.

Core scope:
- RFQ creation and tracking
- Bulk import of inquiry items
- Many-to-many assignment between items and suppliers
- Supplier-specific RFQ document generation
- Quotation import and normalization
- Quotation comparison and award recording
- Historical price and supplier relationship accumulation

## Public repository data policy

This is a public repository.

All repository content must use fictional, anonymized, or placeholder data. Do not commit:
- real company or organization names
- real personal names or contact details
- real customer or supplier identities
- real product, equipment, or project identities
- real ERP/vendor names tied to actual usage
- real commercial prices, quantities, account data, or internal operating statistics
- screenshots or files containing identifiable business information

Examples and test fixtures must use synthetic data only.
